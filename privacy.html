Privacy Policy

Nom Reels Publisher. Last updated: 2 October 2026.

Nom Reels Publisher is a private tool that I (Prod. Nom) use to upload my own videos to my own accounts on Instagram, YouTube and TikTok. It runs on my own computer and is not available to anyone else.

Data accessed

After I authorise the tool with my own account on a platform, it uploads my videos (with title, description, tags, privacy status and publish time where the platform supports it) and reads the name and ID of my own account or channel to confirm which account is connected. It does not access data of any other user.

Data stored

The authorisation tokens issued by each platform are stored on my own computer or in my own private database. The ID and upload date of each uploaded video are kept in a private log. No data is sold or shared with third parties, and the tool uses no cookies or tracking.

YouTube API Services

The tool uses YouTube API Services. By using it, the user (me) agrees to be bound by the YouTube Terms of Service. The Google Privacy Policy applies. Access can be revoked at any time on the Google security settings page.

TikTok and Instagram

The tool uses the TikTok Content Posting API and the Instagram API to send my own videos to my own accounts. Access can be revoked at any time in the settings of the TikTok app (Security & permissions → Manage app permissions) and of Instagram (Apps and websites).

Deleting data

Revoking access on the platform and deleting the stored token removes all authorisation data. The private upload log can be deleted at any time.

Contact

Questions about this policy: send a message to @prod.nom on Instagram.
